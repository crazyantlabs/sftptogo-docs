The SFTP To Go Management API lets you script everything you would otherwise do in the
dashboard: issue and rotate credentials, create share links, build automations that react to
file activity, attach custom domains, and pull audit logs.

## What this API does not do

**It does not transfer files.** Files move over SFTP, FTPS or the S3-compatible endpoint, using
the credentials you create here. There is no upload or download operation in this reference —
that is by design, not an omission.

## Base URL and organization scope

Almost every path is scoped to an organization:

```
https://api.sftptogo.com/organizations/{organizationId}/...
```

Your API key is bound to a single organization, and a request whose `organizationId` does not
match the key's organization is rejected.

The API itself runs in one region. The region you chose for your storage is a property of your
organization, returned on the organization object — it does not change which host you call.

## Conventions

* Request and response bodies are JSON.
* Timestamps are Unix epoch milliseconds unless a field says otherwise.
* Successful responses return the object itself, with no wrapper envelope.
* List endpoints are cursor-paginated. See the Pagination guide.
* Errors share one shape. See the Errors guide.
