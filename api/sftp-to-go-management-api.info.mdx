The SFTP To Go Management API lets you script what you would otherwise do in the dashboard. This reference documents credentials: creating, updating, rotating and removing the logins your users and systems connect with. More of the dashboard is added here as it is documented.

## What this API doesn't do

**It doesn't transfer files.** Files move over SFTP, FTPS or the S3-compatible endpoint, using the credentials you create here. There is no upload or download operation in this reference: that is by design, not an omission.

## Base URL and organization scope

Every path is scoped to an organization: `https://api.sftptogo.com/organizations/{organizationId}/...`

An API key works for one organization only. See [Authentication](https://sftptogo.com/docs/api/authentication) for how keys work.

The API itself runs in one region. The region you chose for your storage is a property of your organization and doesn't change which host you call.

## Conventions

* Request and response bodies are JSON. Successful responses return the object itself, with no wrapper envelope.
* Timestamps are Unix epoch milliseconds unless a field says otherwise.
* List endpoints return one page at a time. Pass `limit`, and follow the `next` link in the `Link` response header for the following page. `X-Total-Count` gives the total, and `X-Total-Count-Exact` says whether it is exact or a lower bound.
* Every error has the same shape: a stable `id` to match on, a `message` for people, and, on a `400`, an `errors` object or list naming the fields that were rejected.
